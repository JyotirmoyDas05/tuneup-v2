# TuneUP - Project Brief

## Overview
TuneUP is a dual-purpose web platform designed for musicians and music organizers. It functions as a marketplace for hiring musical talent (singers, instrumentalists, bands, etc.) while incorporating social media features for networking and collaboration in the music industry.

## Primary Goals
1. Create a unified platform connecting musicians and event organizers
2. Implement both marketplace functionality and social networking features
3. Deliver an engaging user experience with smooth animations and responsive design
4. Build a secure, scalable backend using Appwrite

## Tech Stack
- **Frontend**: React 18, Next.js 15, Tailwind CSS, ShadCN UI
- **Backend**: Appwrite Pro Plan
- **Animations**: GSAP (ScrollTrigger, SmoothScroll)
- **Deployment**: Vercel

## Key Modules
1. User Profiles (Musicians, Bands, Studios, Organizers)
2. Posting & Hiring System
3. Social Feed
4. Discovery & Filtering
5. Chat System

## Current Focus
The immediate priority is to integrate GSAP animations, specifically ScrollTrigger and SmoothScroll features into the landing page, while maintaining the existing static UI components.

## Change Management
- Existing landing page and static UI sections should not be modified unless explicitly requested
- All modifications to landing pages require approval
- Backend architecture updates need review for Appwrite compatibility
